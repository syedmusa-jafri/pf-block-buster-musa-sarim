# pf-block-buster-musa-sarim
pf project by Syed Muhammad Mosa 26L-0026 and Sarim Irfan 26L-0052

The game is block busters in which you control a paddle using left right arrow keys or A and D. Pressing space starts the game while press ESC pauses it.
